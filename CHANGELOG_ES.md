## 1.0.0 — 2026-11-02

Primera versión pública del cliente nativo de Linux inspirado en OPL Manager para Windows.

- Catálogo ISO/ZSO/VCD/UL, base local, búsqueda, filtros y CSV.
- Índices automáticos CD/DVD de 92 bytes y perfiles avanzados.
- Editores CFG/CHT, controles de compatibilidad/GSM y VMC de 8–64 MiB.
- Ocho tipos de arte, alternativas y descargas individuales/por lotes.
- Renombrado seguro, títulos CFG ausentes, conversión ISO/ZSO y cuatro huellas.
- Cinco temas persistentes; UGM predeterminado.
- DEB autocontenido con requisito glibc explícito, AppImage portable x86_64 y paquete de fuentes.
- Documentación principal inglesa y edición española, con autocomprobación aislada.

La validación física PS2 y las funciones no implementadas indicadas en README siguen fuera del alcance verificado.
