[Español](CHANGELOG_ES.md)

## 1.0.0 — 2026-11-02

Initial public release of the native Linux client inspired by OPL Manager for Windows.

- ISO/ZSO/VCD and UL cataloging, local game database, search, filters and CSV.
- Automatic 92-byte CD/DVD indexes and advanced index profiles.
- CFG/CHT editors, compatibility/GSM controls and 8–64 MiB VMC creation.
- Eight artwork types, alternatives and individual/batch downloads.
- Safe renaming, missing CFG titles, ISO/ZSO conversion and four checksums.
- Five persistent themes, with UGM selected by default.
- Self-contained DEB with an explicit glibc requirement, portable x86_64 AppImage and source archive.
- English-first documentation with a Spanish edition and isolated package self-check.

Physical PS2 validation and the unsupported features listed in README remain outside the verified scope.
